# Havn — Furniture Store Landing Page

A furniture e-commerce storefront landing page for a fictional brand, **Havn**: category navigation, shop-by-room cards, product grid with prices, sale badges and colour swatches, and trust sections (delivery, guarantee).

Built with the latest Next.js App Router and Tailwind CSS v4, with typed product data in TypeScript.

## Features

- Category navigation (Living Room, Bedroom, Dining, Kitchen, Office, Outdoor, Lighting, Storage, Sale)
- "Shop by room" section with item counts
- Product cards with material, price, discount, badges (New, Best Seller, Save %) and colour swatches
- Trust blocks: white glove delivery, 10-year guarantee
- Optimised images with `next/image`
- Responsive layout

## Tech stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```
