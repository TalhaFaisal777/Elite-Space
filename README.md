# Havn - furniture store landing page

A landing page for a made-up furniture brand called Havn. It has category navigation, a "shop by room" section, a product grid with prices, discounts, badges and colour swatches, and a few trust sections like delivery and the 10-year guarantee.

Built with Next.js 16 (App Router), React 19, TypeScript and Tailwind CSS v4. The product data is typed and lives at the top of `src/app/page.tsx`, and images go through `next/image`.

## Running it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
